# NAVAVIJAYA — Smart City

**Group 3 · Question 10: Smart City Website**

NavaVijaya is a futuristic smart-city concept website. It presents connected urban services through an editorial landing page and colorful service cards.

## Files
- `index.html` — page content and idea form
- `style.css` — responsive visual system and layouts
- `script.js` — mobile navigation and demo form interaction

## Features
- City concept hero section
- Vision and sustainability introduction
- Six service areas: transportation, healthcare, education, sustainability, public services and safety
- Illustrative city impact metrics
- Interactive idea submission form with on-page confirmation
- Responsive navigation and mobile layout

## Important demo note
NavaVijaya is a fictional smart-city concept. The figures are illustrative targets, not actual city statistics. The idea form only displays a confirmation in the browser; it does not send or store submissions. No real emergency service is provided.

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a repository, for example `navavijaya-smart-city`.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`.
5. Save and wait for GitHub to publish the site.
